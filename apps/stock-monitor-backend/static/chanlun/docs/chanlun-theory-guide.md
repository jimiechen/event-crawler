# 缠论（Chan Theory）画线基础理论文档

> 基于 `test-tool-chanlun.html` 缠论K线图表的实现说明
> 股票示例：舒华体育（605299）日K线图

---

## 一、缠论概述

**缠论**（又称"市场哲学的完全分类"）是由中国人"缠中说禅"于2006-2008年发布的一套股票技术分析理论体系。其核心思想是：

> **对市场走势进行完全几何化的分类，通过分型→笔→线段→中枢的层级结构，实现对价格走势的精确描述和预测。**

与传统的均线、MACD等指标不同，缠论不依赖任何参数，完全基于价格本身的几何形态。

---

## 二、核心概念体系（从底向上）

### 2.1 K线包含关系处理（Inclusion / 包含）

**定义：** 当相邻两根K线存在价格区间重叠时，需要进行合并。

```
规则：
├── 上升趋势中：取高低点的并集（向上包含）
│   即：新高 = max(前高, 后高), 新低 = max(前低, 后低)
│
└── 下降趋势中：取高低点的交集（向下包含）
    即：新高 = min(前高, 后高), 新低 = min(前低, 后低)
```

**代码实现位置：** [chanlun-core.js → `mergeIncludedKLines()`](static/chanlun/js/chanlun-core.js)

**示意图：**
```
上升趋势包含合并（向上）:
    K1: ┌──────┐  High=10
        │      │
        │      │
    K2: │  ┌───┼──┐  High=12 ← 取max(10,12)=12
        │  │   │   │
        └──┼───┘   │  Low=8  ← 取max(7,8)=8
           │       │
           └───────┘
    合并后: High=12, Low=8 (范围扩大)
```

### 2.2 分型（Fractal / 分型）

**定义：** 由三根经过包含处理后的相邻K线组成的顶或底形态。是缠论最基础的几何单元。

#### 顶分型（Top Fractal）

```
     中间K线的最高点 > 左边K线的最高点
  AND 中间K线的最高点 > 右边K线的最高点

        ╱╲
       ╱  ╲          ← 中间K线（第2根）
   ╱╲╱    ╲╱╲
  K1   K2   K3

  条件: High(K2) > High(K1) AND High(K2) > High(K3)
```

**视觉特征：** 中间的K线像一座"山峰"，左右两边更低。

#### 底分型（Bottom Fractal）

```
     中间K线的最低点 < 左边K线的最低点
  AND 中间K线的最低点 < 右边K线的最低点

           ╲╱
         ╱    ╲        ← 中间K线（第2根）
    ╱╲╱        ╲╱╱
   K1   K2     K3

  条件: Low(K2) < Low(K1) AND Low(K2) < Low(K3)
```

**视觉特征：** 中间的K线像一个"山谷"，左右两边更高。

#### 有效分型的条件

1. 三根K线必须**连续**（中间不能有间隔）
2. 必须先进行**包含关系处理**
3. 顶分型和底分型必须**交替出现**

---

### 2.3 笔（Bi / 笔）

**定义：** 连接相邻的**顶分型和底分型**之间的线段，是缠论的第二层结构。

#### 笔的基本规则

```
规则1: 笔的起点和终点必须是分型（顶或底）
规则2: 相邻的两笔方向必须相反（一上一下交替）
规则3: 一笔至少包含5根K线（起点分型3根 + 终点分型之间至少1根独立K线）
规则4: 同类型分型之间至少有1根非共用K线（即顶-底之间≥1根K线）
```

#### 笔的方向判定

```
上升笔（Up Bi）: 从底分型 → 顶分型
                endPrice > startPrice
                
下降笔（Down Bi）: 从顶分型 → 底分型
                  endPrice < startPrice
```

#### 示意图

```
价格
 ↑
 │         ● 顶分型(Top)        ● 顶分型
 │        ╱ ╲                  ╱ ╲
 │   ●底 ╱   ╲●底      ●底 ╱   ╲●底
 │  ╱ ╲╱     ╲╱ ╲    ╱ ╲╱     ╲╱ ╲
 │ K1 K2 K3  K4 K5 K6 K7 ...
 │
 └──────────────────────────→ 时间

笔1(上升): 底(K1-K3) → 顶(K3-K5)  ← 紫色细线 #6366f1
笔2(下降): 顶(K3-K5) → 底(K5-K7)  ← 紫色细线 #6366f1
笔3(上升): 底(K5-K7) → 顶(...)    ← 紫色细线 #6366f1
```

**代码实现位置：** [chanlun-core.js → `detectBis()`](static/chanlun/js/chanlun-core.js)

**图表渲染：**
- 颜色：`#6366f1`（靛蓝/紫色）
- 线宽：`1.5px`
- 端点：圆点标记（顶=红色`#ef4444`，底=绿色`#22c55e`）

### 2.4 线段（XianDuan / 线段）

**定义：** 由至少**3笔**组成的、同方向的更大级别结构。是缠论的第三层结构。

#### 线段的构成规则

```
规则1: 至少由3个同向笔组成
规则2: 线段内部可以包含反向笔（波动）
规则3: 反向笔不能破坏线段的整体方向
    （即反向笔的极值不能超过线段起点）
```

#### 线段的破坏条件

```
上升线段被破坏: 出现一个下降笔，其终点价格 < 上升线段起点的最低价
下降线段被破坏: 出现一个上升笔，其终点价格 > 下降线段起点的最高价
```

#### 示意图

```
价格
 ↑
 │                    ★ 线段终点
 │                   ╱
 │              ╱╲  ╱
 │            ╱    ╲╱   ← 内部波动笔（不破坏）
 │          ╱  笔2   ╲
 │        ╱╲        ╲
 │  ★起点╱  ╲笔1    ╲★破坏点(如低于起点则线段结束)
 │      ╱    ╲      ╲
 │
 └──────────────────────→ 时间

线段(上升): 起点 → 终点 (由笔1+笔2+... ≥3笔组成)
颜色: #ef4444 (红色，上升) 或 #22c55e (绿色，下降)
线宽: 2.5px (比笔更粗)
```

**代码实现位置：** [chanlun-core.js → `detectXianduans()`](static/chanlun/js/chanlun-core.js)

### 2.5 中枢（ZhongShu / 中枢）

**定义：** 价格在某个区间内反复震荡形成的**密集成交区域**。至少由**3笔**的重叠区间构成。

#### 中枢的构成条件

```
条件1: 至少有3个笔进入该价格区间
条件2: 存在一个价格区间 [ZD, ZG]，使得:
        - 至少3笔的低点 ≤ ZG（中枢上沿）
        - 至少3笔的高点 ≥ ZD（中枢下沿）
        - ZG > ZD（上沿必须大于下沿）
```

#### 中枢的关键参数

| 参数 | 英文 | 定义 | 图表显示 |
|------|------|------|---------|
| **ZG** | ZhongShu Gao | 中枢上沿 = 重叠区间的最高低点上限 | 浅蓝色矩形顶部 |
| **ZD** | ZhongShu Di | 中枢下沿 = 重叠区间的最低高点下限 | 浅蓝色矩形底部 |
| **ZZ** | ZhongShu Zhong | 中枢中枢 = (ZG + ZD) / 2 | — |
| **ZG-ZD** | — | 中枢振幅 | 矩形高度 |

#### 示意图

```
价格
 ↑              ZG ──────────────────────── 中枢上沿
 │             ╱│╲                          ← 浅蓝矩形区域
 │      ╱╲   ╱ │ ╲   ╱╲
 │    ╱    ╲╱  │  ╲╱    ╲
 │   │笔1  笔2│  笔3    │  ← 至少3笔在此区间内重叠
 │              │
 │    ZD ───────┴─────────────────────── 中枢下沿
 │
 └────────────────────────────────────→ 时间

中枢区间: [ZD, ZG] = 浅蓝色半透明矩形 (#38bdf8, opacity=0.08)
边框: 虚线 (#38bdf8, strokeDasharray='3,3')
```

#### 中枢的意义

1. **多空博弈区域**: ZG之上多头占优，ZD之下空头占优
2. **买卖参考**:
   - 价格突破ZG且回踩不破 → 买入信号
   - 价格跌破ZD且反弹不过 → 卖出信号
3. **级别递归**: 大级别的笔可能构成小级别的中枢

**代码实现位置：** [chanlun-core.js → `detectZhongshus()`](static/chanlun/js/chanlun-core.js)

## 三、层级关系总结

```
层级0: 原始K线数据 (OHLCV)
    ↓ 包含关系处理
层级1: 分型 (Fractal) — 顶分型 / 底分型
    ↓ 相邻分型连接
层级2: 笔 (Bi) — 上升笔 / 下降笔 (紫色细线 1.5px)
    ↓ ≥3笔同向 + 不被破坏
层级3: 线段 (XianDuan) — 上升线段 / 下降线段 (红/绿粗线 2.5px)
    ↓ ≥3笔重叠 [ZD, ZG]
层级4: 中枢 (ZhongShu) — 密集成交区 (浅蓝矩形)
```

```

            │

            ├──────────────→ 输出: biData[]
            │
            ▼

            │
            ▼
┌───────────────────────┐
│  Step 4b: 中枢检测      │  detectZhongshus()
│  ≥3笔重叠形成[ZD,ZG]   │  ZG > ZD 的价格区间
└───────────┬───────────┘
            │
            ├──────────────→ 输出: zhongshuData[]
            │
            ▼
┌───────────────────────┐
```

## 七、使用指南

1. 打开页面 → 输入股票代码 → 点击「添加自定义股票」

## 八、注意事项

1. **数据要求**: 至少需要 **5根K线** 才能开始缠论分析（最少3根用于第一个分型）
2. **分型有效性**: 顶分型和底分型必须严格交替出现，连续两个同类型分型只保留更极端的那个
3. **笔的最小长度**: 一笔至少跨越 **5根K线**（含两端分型各3根，中间共享1根 + 至少1根独立）
4. **中枢的有效性**: ZG 必须 > ZD，否则该区间不构成有效中枢
5. **线段的破坏**: 只有当反向笔的极值**穿越**线段起点的极端价格时，才认为线段被破坏
6. **实时性**: 通达信TDX数据源需保持客户端登录状态，否则无法获取最新行情
