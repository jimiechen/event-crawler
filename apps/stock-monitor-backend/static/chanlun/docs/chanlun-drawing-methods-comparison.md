# 缠论画法对比：标准缠论 vs 实战简化版（参考图画法）

> 知识库文档 | 版本 v1.0 | 创建日期: 2026-04-05
> 适用场景：理解不同缠论画法工具/软件的差异，选择适合自身交易风格的画法体系

---

## 一、两种缠论画法的定位

### 1.1 标准缠论（教科书级 / 108课体系）

- **来源**: 缠中说禅《教你炒股票108课》（2006-2008）
- **定位**: 数学化、公理化、完全分类的市场理论
- **特点**: 规则严格，定义精确，适合理论学习和程序化自动实现
- **代表工具**: 原教旨缠论分析软件、学术型量化系统

### 1.2 实战简化版（参考图画法 / 软件默认风格）

- **来源**: 国内主流交易软件（同花顺、通达信缠论插件）的默认画法
- **定位**: 快速看盘、一眼识别趋势结构的实用主义流派
- **特点**: 规则放宽，视觉友好，允许人工确认和主观筛选
- **代表工具**: 同花顺缠论主图指标、通达信缠论划线、各类看盘APP

> **核心区别**: 标准缠论追求"数学上的完全分类"，实战版追求"视觉上的一眼可读"

## 二、颜色体系对比

| 元素 | 标准缠论 | 实战简化版（参考图） | 设计逻辑差异 |
|:---:|:---:|:---:|---|
| **笔 (Bi)** | `#6366f1` 靛蓝/紫色 | `#dc2626` **红色** | 标准用冷色表示"中性结构"；实战用红色突出"基础交易单元"，在K线图上更醒目 |
| **线段 (XD)** | 上升`#ef4444`红 / 下降`#22c34a`绿 | 统一 `#3b82f6` **蓝色** | 标准模仿K线涨跌色（方向着色）；实战用蓝色统一表示"趋势框架"，避免与K线红绿色混淆 |
| **中枢小 (ZS)** | 统一浅蓝 `#38bdf8` | `#a855f7` **紫色虚线** | 新增维度：按振幅大小区分中枢类型 |
| **中枢大 (ZS)** | 统一浅蓝 `#38bdf8` | `#22d3ee` **青色填充** | 大中枢用更醒目的颜色和填充效果 |
| **背驰标记** | 无内置标记 | 绿色圆圈 + `⊘` 符号 | 实战版独有：预设关键位置的人工标注 |

### 颜色设计哲学

```
标准缠论的配色逻辑:
  K线(红涨绿跌) → 线段也(红涨绿跌) → 方向一致性
  笔用紫色 → 中性、不干扰K线颜色

实战版的配色逻辑:
  笔=红色 → 最细最密的基础线条，用暖色吸引注意力
  线段=蓝色 → 较粗的趋势骨架，用冷色与红色笔形成冷暖对比
  中枢=紫/青 → 区域填充色，不抢线条的风头
  整体: 红(细节) + 蓝(框架) + 紫/青(区域) = 层次分明
```

## 三、笔（Bi）的画法差异

### 3.1 共同规则（两者一致）

```
规则1: 笔的起点和终点必须是分型（顶分型或底分型）
规则2: 相邻两笔的方向必须严格交替（UP→DOWN→UP→DOWN...）
规则3: 端点取极值
       ↑ 上升笔: 起点=底分型的Low, 终点=顶分型的High
       ↓ 下降笔: 起点=顶分型的High, 终点=底分型的Low
规则4: 同类型分型之间至少有1根独立K线（gap ≥ 1）
```

### 3.2 关键差异

| 方面 | 标准缠论 | 实战简化版 |
|------|---------|-----------|
| **最小K线数** | 严格 ≥ 5根（含两端分型各3根，中间共享+至少1独立） | 更宽松，允许短笔存在 |
| **笔的合并** | 不合并。中间任何有效反向分型都会产生新笔 | **允许长周期笔**：中间的小波动不拆分为独立笔 |
| **笔的数量确定** | 纯算法自动输出 | 半自动：算法初筛 + 人工确认/调整 |
| **特殊处理** | 无 | 可能对某些"噪音笔"进行合并或忽略 |

### 3.3 典型案例：长周期笔的处理

以605299.SH（2025-08-28 ~ 2026-04-03）为例：

```
价格走势:
  13.35 ┤                              ╱╲
        │                     ╱╲    ╱  ╲
  12.00 ┤           ╱╲      ╱  ╲  ╱    ╲
        │     ╱╲   ╱  ╲    ╱    ╲╱      ╲
  11.00 ┤    ╱  ╲ ╱    ╲──╱              ╲___ 11.61
        │   ╱    ╳                          (03-04)
  10.99 ┤__╱  (01-28)
        │
  └────┴──────────────────────────────────────→ 时间
       01-22  01-28  01-29          03-04

标准缠论可能产出:
  笔A(DOWN): 0122/H:13.35 → 0128/L:10.99   ← 暴跌段
  笔B(UP):   0128/L:10.99 → 0129/H:11.20   ← 反弹段
  笔C(DOWN): 0129/H:11.20 → 0304/L:11.61   ← 阴跌段
  → 3条短笔，每条都有明确的分型转换

参考图的实际产出:
  笔10(DOWN): 0122/H:13.35 → 0304/L:11.61   ← 1条长笔！
  → 合并了整个2个月的回调过程为单条笔
  → 理由: 中间的反弹(10.99→11.20)幅度不够形成有效的底+顶分型对
    或: 即使形成了分型，也被视为"笔内波动"而忽略
```

## 四、线段（XianDuan）的画法差异 — 最大区别！

### 4.1 构成条件

| 条件 | 标准缠论 | 实战简化版 |
|------|:---:|:---:|
| **最少笔数** | **≥ 3笔**（严格） | **≥ 2笔**（放宽） |
| **方向一致性** | 内部主导方向一致 | 一致 |
| **破坏判定方法** | 特征序列法（复杂，见下文） | 价格穿越法（简单，见下文） |

### 4.2 破坏条件详解

#### 标准缠论的特征序列法（原教旨）

```
上升线段的破坏判断:

  步骤1: 找出线段内所有"向下笔"（反向笔）
  步骤2: 将这些向下笔的起点组成"特征序列"
  步骤3: 在特征序列中找分型:
          如果出现一个"顶分型"(即序列中某元素 > 左右元素)
          → 该位置就是"第一元素"
  步骤4: 从第一元素之后继续找:
          如果再出现一个"顶分型"
          → 形成"第二特征序列分型"
          → 线段被破坏！

  示意图:
  特征序列(各反向笔的低点):  [12, 11, 11.5, 10.5, 11]
                               ↑           ↑
                           第一元素?    第二元素?
                           (如果11<12且11<11.5) (如果10.5<11.5且10.5<11)
                           → 第一元素成立  → 第二元素成立!
                           → 线段被破坏!

  ★ 这种方法的优点: 精确，排除假突破
  ★ 缺点: 复杂，需要编程实现，手工判断困难
```

#### 实战简化版的价格穿越法

```
上升线段的破坏判断:

  只有一个条件:
    如果任何一个反向笔的终点价格 < 线段起点的最低价
    → 线段被破坏！

  示意图:
  价格
   ↑
   │  ╭─ 线段起点(Low=9.27)
   │  │
   │  │     ╭─── 反向笔终点 = 9.0
   │  │     │    9.0 < 9.27 ✓
   │  │     │    → 破坏!
   │  │  ╰───╯
   │  │
   └──┼──────────────────→ 时间

  ★ 优点: 极其简单，一眼可判
  ★ 缺点: 可能过早判定破坏（假突破也会触发）
```

### 4.3 线段终点选择的差异（关键！）

这是导致两种画法**视觉效果差异最大**的地方：

```
以605299.SH为例:

标准缠论可能的线段划分:
  线段1(UP): 1017/L:8.85 → 1210/H:17.25
  ↑ 终点选在最高点，因为17.25后出现了有效破坏

  线段2(DOWN): 1210/H:17.25 → 1217/L:11.22 或后续低点
  ↑ 但这里只有1笔(笔6)，不够3笔，可能不构成线段
  → 导致线段2"缺失"或延后

参考图的线段划分:
  线段1(UP): 0828/L:9.27 → 1225/H:12.48
  ↑ 终点选在12.25而非17.25！
  ↑ 原因: 17.25后的急速回落被视为"线段外部的极端波动"
  ↑ 12.25是一个更"温和"的、有结构意义的高点

  线段2(DOWN): 1225/H:12.48 → 0304/L:11.61
  ↑ 包含笔8(DOWN) + 笔9(UP) + 笔10(DOWN) = 3笔 ✓
  ↑ 这是一个标准的"回调线段"
```

> **为什么参考图不把17.25作为线段终点？**
>
> 因为从12.25到17.25再到11.22的过程太剧烈（+38%然后-35%），这种V型反转在实战中通常被视为**"趋势外的异常波动"**或**"新趋势的开始信号"**，而不是原有线段的自然终结。实战派倾向于在**结构性的转折点**（如12.25这个震荡高点）结束线段。

## 五、中枢（ZhongShu）的画法差异

### 5.1 基本定义（两者一致）

```
中枢 = 至少3笔的价格重叠区间

ZG (上沿) = 重叠区间的上限
            = 所有进入中枢笔中，上升笔的最高点的最小值
            (或简化: 进入笔的高点中的某个统计值)

ZD (下沿) = 重叠区间的下限
            = 所有进入中枢笔中，下降笔的最低点的最大值

必要条件: ZG > ZD (必须有实际重叠)
```

### 5.2 样式差异

| 属性 | 标准缠论 | 实战简化版 |
|------|---------|-----------|
| **样式数量** | 单一颜色 | **双样式**（按振幅分类） |
| **小中枢** | 与大中枢相同 | 紫色 `rgba(139,92,246,0.06)` + `#a855f7` 虚线 `4,3` |
| **大中枢** | 与小中枢相同 | 青色 `rgba(103,232,249,0.12)` + `#22d3ee` 虚线 `4,4` |
| **分类阈值** | 无 | 振幅 < 1.0 为"小中枢" |
| **语义含义** | 仅表示重叠区 | 小="紧凑筑底/筑顶", 大="宽松整理" |

### 5.3 双样式的实战意义

```
价格
  │
12.49├───────────┐
     │  ╭─────╮  │ ← 中枢2 (大) 青: 振幅≈1.26 "宽松整理"
12.04├─┤  ╭╮  ├─┤    多空充分换手，后续变盘力度大
     │  │ │  │  │
11.57├─┤─╯╰──├─┤
     │  │     │  │
11.22├──┴─────┴──┘
     │
 9.30├──╮         ← 中枢1 (小) 紫: 振幅≈0.45 "紧凑筑底"
     │  ╰╮          价格密集收敛，方向选择迫近
 8.85├────╯         历史最低点附近
     │
  └──┬────┬────────┬──→ 时间
     9月  10月      12月  1月  2月
```

## 六、背驰（Divergence）标识

### 6.1 标准缠论的背驰理论

```
背驰的定义:
  当一个走势创出了新高（或新低），但推动该走势的"力度"
  相比前一次同方向的走势减弱时，就形成了背驰

力度的衡量方法:
  方法1: MACD面积法（最常用）
    - 计算两次上涨段对应的MACD柱子面积
    - 后一次面积 < 前一次面积 → 背驰

  方法2: MACD高度法（简化版）
    - 比较两次上涨段结束时的MACD柱子高度（或DIF值）
    - 后一次 < 前一次 → 背驰

  方法3: 斜率法
    - 比较两次上涨段的斜率（价格变化/时间变化）
    - 后一次斜率 < 前一次斜率 → 背驰

背驰的类型:
  顶背驰: 上涨创新高但力度减弱 → 见顶信号
  底背驰: 下跌创新低但力度减弱 → 见底信号
```

### 6.2 参考图的背驰标记

```
参考图的做法（大幅简化）:

  不进行实时算法检测背驰
  而是在特定位置预置 ⊘ 标记

  标记规则:
  位置: 第N条笔的终点（通常是第3条UP笔的顶分型处）
  样式: 绿色空心圆圈(r=9) + 内部 Ø 字符(15px粗体)
  含义: "此处发生了顶背驰，注意风险"

  以605299为例:
  笔3(UP): 1017/L:8.85 → 1105/H:10.25
  在 1105/H:10.25 处画 ⊘
  佐证: 当日巨量(1732万手)，上影线长(H=10.25, C=9.89)

  ★ 这是一种"事后确认"式的标记
  ★ 不是预测性信号，而是历史经验总结
```

## 七、完整层级对比

### 7.1 标准缠论层级

```
Level 0: 原始K线 (OHLCV)
    ↓ 包含关系处理 (向上取并集 / 向下取交集)
Level 1: 分型 (Fractal)
    ↓ 顶分型 ↔ 底分型 严格交替
Level 2: 笔 (Bi) — [紫色 1.5px]
    ↓ gap ≥ 1, 严格交替
Level 3: 线段 (XianDuan) — [红/绿 2.5px]
    ↓ ≥3笔 + 特征序列破坏判定
Level 4: 中枢 (ZhongShu) — [浅蓝矩形]
    ↓ ≥3笔价格重叠 [ZD, ZG]
Level 5: 趋势/买卖点
    ↓ 中枢突破 + 背驰判断
Level 6: 操作决策
```

### 7.2 实战简化版层级

```
Level 0: 原始K线 (OHLCV)
    ↓ 包含处理（基本相同）
Level 1: 分型 (Fractal) — 基本相同
    ↓ 但可能有筛选（过滤弱分型）
Level 2: 笔 (Bi) — [红色 1.5px] ⚠️ 颜色不同
    ↓ 允许长周期笔（合并小波动）
Level 3: 线段 (XianDuan) — [蓝色 3.5px] ⚠️ 颜色+规则不同
    ↓ ≥2笔即可 + 价格穿越破坏
Level 4: 中枢 (ZhongShu) — [紫/青双色] ⚠️ 双样式
    ↓ 基本相同，新增大小分类
Level 5+: 背驰标记 ⊘ — ⚠️ 独有元素
         直接在关键位置标注
```

## 八、优缺点对比总结

| 维度 | 标准缠论 | 实战简化版 |
|------|:---:|:---:|
| **严谨性** | ★★★★★ 公理化的数学体系 | ★★★☆☆ 存在模糊地带 |
| **自动化难度** | ★★☆☆☆ 特征序列法复杂 | ★★★★★ 规则简单易编程 |
| **视觉清晰度** | ★★★☆☆ 颜色可能与K线冲突 | ★★★★★ 红蓝对比鲜明 |
| **学习门槛** | ★☆☆☆☆ 需要深入理解108课 | ★★★★☆ 直观易懂 |
| **假信号敏感度** | 低（严格过滤） | 高（宽松规则可能引入噪音） |
| **灵活性** | 低（规则固定） | 高（允许人工调整） |
| **适用场景** | 程序化交易 / 量化回测 / 理论研究 | 日常看盘 / 快速分析 / 手动交易 |
| **主要风险** | 过于严格可能漏掉有效信号 | 过于宽松可能产生无效信号 |

## 九、如何选择适合自己的画法

### 选择标准缠论，如果你：

- 正在学习缠论理论，需要建立正确的概念框架
- 在做程序化交易或量化回测，需要确定的、可复现的规则
- 追求"完全分类"，不接受模糊地带
- 有足够的时间进行复杂的图表分析

### 选择实战简化版，如果你：

- 主要做手动交易的日常看盘
- 需要"一眼看清"趋势结构
- 更关注大级别的走势，不需要纠结于每一根笔
- 使用的是商业交易软件（它们大多采用简化版）
- 时间有限，需要快速做出交易决策

### 混合使用（推荐）：

```
日常看盘: 用实战简化版（红色笔 + 蓝色线段 + 双色中枢）
  → 快速识别趋势方向和关键位置

深度分析: 用标准缠论（特征序列破坏 + MACD背驰计算）
  → 确认关键转折点的有效性

记录交易: 两种都画，对比差异
  → 差异本身就是信息（当两种画法给出不同结论时，特别值得关注）
```
