如何实现这个消息解读技术架构

Thought for 43 seconds

我们被问到："如何实现这个消息解读技术架构"，基于给定的文件内容。文件描述了一个称为"5问6有定主流"的方法，用于确定主流题材。它涉及两个主要步骤：1）消息出来当晚，用基本面5问做主观判断；2）题材爆发第一天开盘，用盘面6有做客观判断。然后，在爆发首日，确定主流题材后，不再犹豫，最重要的是在车上。

我们需要设计一个技术架构来实现这个消息解读系统。这应该是一个系统或软件架构，能够帮助投资者或交易者快速识别和确认主流题材。

让我们分析需求：

1. 消息收集：系统需要从各种来源收集新闻、公告、社交媒体等信息。
2. 基本面分析（5问）：对每个重要的消息，系统需要评估其是否符合“5问”：突发性、大事件、想象空间、预期、情绪。这可能需要自然语言处理（NLP）和情感分析。
3. 盘面分析（6有）：在题材爆发的第一天开盘时，系统需要监控市场数据以评估“6有”：有宽度、有强度、有容量、有弹性、有高度、有深度。这需要实时市场数据，如股票价格、成交量、板块表现等。
4. 决策支持：系统应给出是否主流题材的判断，并可能提供交易建议。

因此，技术架构可能包括以下组件：

* 数据采集层：从新闻源、社交媒体、财经网站等收集实时信息。
* 数据处理与存储层：清洗、存储和管理数据。
* 消息分析引擎：使用NLP技术分析消息内容，提取关键信息，并进行“5问”评估。
* 市场数据监控：实时接收市场数据，计算技术指标，评估“6有”条件。
* 决策引擎：结合消息分析和市场监控的结果，判断主流题材，并生成信号。
* 用户界面：展示分析结果、信号和推荐。

考虑到这是一个金融科技系统，还需要考虑实时性、可扩展性、可靠性和安全性。

让我们详细设计每个部分。

### 1. 数据采集层

* 新闻API：从主流财经新闻网站、交易所公告等获取新闻。
* 社交媒体API：如Twitter、微博等，捕捉市场情绪和突发消息。
* 市场数据API：获取实时股票行情、板块数据、指数数据等。
* 计划任务：定期爬取或订阅流式数据。

### 2. 数据处理与存储

* 消息队列：用于实时数据流，如Kafka或RabbitMQ。
* 数据库：存储历史新闻、市场数据、分析结果。可使用时序数据库（如InfluxDB）存储市场数据，关系数据库（如PostgreSQL）存储结构化信息，NoSQL（如MongoDB）存储非结构化新闻数据。
* 数据清洗：去除重复、无关信息，提取文本内容。

### 3. 消息分析引擎（5问）

* 自然语言处理：分词、实体识别（公司、行业、概念）、情感分析。
* 规则引擎或机器学习模型：评估每个消息的“5问”指标：

  + 突发性：消息发布的时间是否突然？与历史模式相比？
  + 大事件：消息是否涉及重大政策、技术突破、行业变革等？可通过关键词和影响范围判断。
  + 想象空间：消息是否具有长远影响？行业空间是否巨大？可能需要结合行业知识库。
  + 预期：消息是否超出市场预期？可对比分析师预测或历史数据。
  + 情绪：市场情绪是积极还是消极？情感分析得分。
* 输出：对每个消息或题材给出评分或标签。

### 4. 市场数据监控（6有）

* 实时数据流处理：使用流处理框架（如Apache Flink、Spark Streaming）计算实时指标。
* “6有”指标定义：

  + 有宽度：板块内涨停股票数量多，扩散范围广。计算板块内上涨股票比例。
  + 有强度：涨停板封单金额大，涨幅大。计算平均涨幅、封单量。
  + 有容量：板块市值大，成交额大。计算板块总市值和成交额。
  + 有弹性：个股波动大，弹性好。可能用波动率指标。
  + 有高度：龙头股连续涨停，空间大。追踪龙头股连板数。
  + 有深度：题材有纵深，细分领域多。分析产业链上下游公司表现。
* 这些指标需要针对每个题材或板块进行计算，并设定阈值或相对排名。

### 5. 决策引擎

* 融合消息分析评分和市场监控指标，给出综合判断。
* 规则：例如，消息分析评分高且市场监控指标满足多个“6有”条件，则确认为主流题材。
* 可设置预警：当条件满足时，发送通知（如邮件、短信、APP推送）。

### 6. 用户界面

* Web仪表盘：展示热门题材、评分、推荐操作。
* 移动端：方便实时接收信号。
* 历史回测：验证策略有效性。

### 7. 其他考虑

* 回测模块：使用历史数据验证“5问6有”策略的表现。
* 机器学习优化：利用历史数据训练模型，提高判断准确性。
* 风险控制：设置止损、仓位管理等。

### 实现技术栈建议

* 后端：Python（用于数据分析、NLP）、Java/Scala（用于高并发实时处理）
* 前端：React/Vue
* 数据库：PostgreSQL, InfluxDB, Elasticsearch（用于全文搜索）
* 消息队列：Kafka
* 流处理：Flink或Spark Streaming
* 部署：Docker, Kubernetes

### 总结

from datetime import datetime, timedelta
import json

class FiveQuestionsAnalyzer:
    """5问分析引擎"""
    
    def __init__(self):
        # 定义数据流
        self.news_table = self._create_news_stream()
        self.sentiment_table = self._create_sentiment_stream()
        
        # 5问分析管道
        self.analysis_result = self._build_five_questions_pipeline()
    
    def _create_news_stream(self):
        """创建新闻数据流"""
        return pw.io.kafka.read(
            rdkafka_settings={
                'bootstrap.servers': 'localhost:9092',
                'group.id': 'five_questions_analyzer'
            },
            topic='financial_news',
            format='json',
            value_columns=['title', 'content', 'source', 'timestamp'],
            autocommit_duration_ms=1000
        )
    
    def _create_sentiment_stream(self):
        """创建社交媒体情绪流"""
        return pw.io.kafka.read(
            rdkafka_settings={
                'bootstrap.servers': 'localhost:9092',
                'group.id': 'sentiment_analyzer'
            },
            topic='social_sentiment',
            format='json'
        )
    
    def _build_five_questions_pipeline(self):
        """构建5问分析管道"""
        
        # 1. 突发性分析
        def calc_suddenness(news_group):
            """计算新闻突发性"""
            timestamps = news_group.timestamp
            if len(timestamps) < 2:
                return 0.0
            
            intervals = []
            sorted_ts = sorted(timestamps)
            for i in range(1, len(sorted_ts)):
                interval = (sorted_ts[i] - sorted_ts[i-1]).total_seconds()
                intervals.append(interval)
            
            avg_interval = sum(intervals) / len(intervals)
            # 间隔越短，突发性越高
            return min(100, 1000 / max(avg_interval, 1))
        
        # 2. 大事件检测
        big_event_keywords = ['政策', '突破', '并购', '重组', '重大', '首次']
        
        def calc_event_scale(content: str) -> float:
            """计算事件规模"""
            score = 0
            content_lower = content.lower()
            
            for keyword in big_event_keywords:
                if keyword in content_lower:
                    score += 15  # 每个关键词15分
            
            # 检查是否涉及多个行业
            industries = ['新能源', '半导体', '医药', '人工智能', '消费']
            industry_count = sum(1 for ind in industries if ind in content_lower)
            score += min(25, industry_count * 10)  # 最多25分
            
            return min(score, 100)
        
        # 3. 想象空间评估
        def calc_imagination_space(content: str) -> float:
            """评估想象空间"""
            future_words = ['未来', '预计', '有望', '潜力', '增长', '空间', '蓝海']
            score = 0
            
            for word in future_words:
                count = content.count(word)
                score += count * 5
            
            # 检查是否有具体数字预测
            import re
            number_patterns = r'增长(\d+)%|达到(\d+)亿|空间(\d+)倍'
            matches = re.findall(number_patterns, content)
            if matches:
                score += 30
            
            return min(score, 100)
        
        # 应用转换
        analyzed_news = self.news_table.select(
            *pw.this,
            suddenness=pw.apply(calc_suddenness, pw.this.content),
            event_scale=pw.apply(calc_event_scale, pw.this.content),
            imagination=pw.apply(calc_imagination_space, pw.this.content),
            # 继续其他指标...
        )
        
        return analyzed_news

class SixHasAnalyzer:
    """6有分析引擎"""
    
    def __init__(self, redis_client):
        self.redis = redis_client
        
        # 市场数据流
        self.market_table = pw.io.websocket.read(
            url='ws://market-data:8080/realtime',
            format='json',
            value_columns=['symbol', 'price', 'volume', 'change', 'timestamp']
        )
    
    def analyze_six_has(self, sector_code: str):
        """实时计算6有指标"""
        
        # 按板块过滤
        sector_stocks = self.market_table.filter(
            pw.this.sector == sector_code
        )
        
        # 有宽度：上涨家数占比
        rising_stocks = sector_stocks.filter(pw.this.change > 0)
        width = (rising_stocks.groupby(pw.this.sector).reduce(
            total_count=pw.reducers.count(),
            rising_count=pw.reducers.count(pw.this.change > 0)
        ).select(
            width_ratio=pw.this.rising_count / pw.this.total_count * 100
        ))
        
        # 有强度：涨停板分析
        limit_up_stocks = sector_stocks.filter(pw.this.change >= 9.8)  # 涨停
        strength = limit_up_stocks.groupby(pw.this.sector).reduce(
            limit_up_count=pw.reducers.count(),
            total_amount=pw.reducers.sum(pw.this.volume * pw.this.price)
        )
        
        # 有容量：成交额
        capacity = sector_stocks.groupby(pw.this.sector).reduce(
            total_turnover=pw.reducers.sum(pw.this.volume * pw.this.price),
            avg_turnover=pw.reducers.avg(pw.this.volume * pw.this.price)
        )
        
        # 合并所有指标
        six_has_result = pw.join(
            width, strength, capacity,
            id=width.sector
        ).select(
            *pw.this,
            # 计算综合得分
            comprehensive_score=(
                pw.this.width_ratio * 0.2 +
                pw.this.limit_up_count * 0.3 +
                pw.this.total_turnover / 1000000 * 0.5  # 单位：百万
            )
        )
        
        # 实时写入Redis供查询
        @pw.udf
        def update_redis(sector: str, data: dict):
            asyncio.create_task(
                self.redis.hset(
                    f'sector:{sector}:six_has',
                    mapping=data
                )
            )
            asyncio.create_task(
                self.redis.expire(
                    f'sector:{sector}:six_has',
                    300  # 5分钟过期
                )
            )
            return True
        
        six_has_result.select(
            updated=update_redis(pw.this.sector, pw.this.to_dict())
        )
        
        return six_has_result

import json

import redis.asyncio as redis
from typing import Dict, List, Optional

class AnalysisCacheManager:
    """管理所有缓存和状态"""
    
    def __init__(self):
        self.client = redis.Redis(
            host='localhost',
            port=6379,
            decode_responses=True,
            max_connections=20
        )
        
        # 定义缓存键结构
        self.keys = {
            'topic_heat': 'topics:heat:rank',  # ZSET 题材热度榜
            'five_questions': 'topic:{topic_id}:5q',  # HASH 5问分析结果
            'six_has': 'sector:{sector}:6h',  # HASH 6有实时指标
            'user_states': 'user:{user_id}:state',  # HASH 用户状态
            'signal_queue': 'signals:pending',  # LIST 待处理信号
            'historical': 'topic:{topic_id}:historical'  # STREAM 历史数据
        }
    
    async def cache_five_questions_result(self, topic_id: str, result: Dict):
        """缓存5问分析结果"""
        key = self.keys['five_questions'].format(topic_id=topic_id)
        
        # 存储结构化结果
        await self.client.hset(key, mapping={
            'suddenness': result.get('suddenness', 0),
            'event_scale': result.get('event_scale', 0),
            'imagination': result.get('imagination', 0),
            'expectation_gap': result.get('expectation_gap', 0),
            'sentiment': result.get('sentiment', 0),
            'comprehensive_score': result.get('comprehensive_score', 0),
            'updated_at': datetime.now().isoformat()
        })
        
        # 设置过期时间（24小时）
        await self.client.expire(key, 86400)
        
        # 更新热度榜
        await self.client.zadd(
            self.keys['topic_heat'],
            {topic_id: result.get('comprehensive_score', 0)}
        )
    
    async def get_real_time_six_has(self, sector_code: str) -> Optional[Dict]:
        """获取实时6有指标"""
        key = self.keys['six_has'].format(sector=sector_code)
        
        data = await self.client.hgetall(key)
        if not data:
            return None
        
        # 检查数据是否过期
        updated_at = data.get('updated_at')
        if updated_at:
            update_time = datetime.fromisoformat(updated_at)
            if datetime.now() - update_time > timedelta(minutes=5):
                return None  # 数据过期
        
        return {
            'width': float(data.get('width_ratio', 0)),
            'strength': int(data.get('limit_up_count', 0)),
            'capacity': float(data.get('total_turnover', 0)),
            'elasticity': float(data.get('elasticity', 0)),
            'height': float(data.get('height_score', 0)),
            'depth': float(data.get('depth_score', 0)),
            'comprehensive_score': float(data.get('comprehensive_score', 0))
        }
    
    async def update_topic_heat_ranking(self):
        """更新题材热度排行榜"""
        # 获取前20名热门题材
        hot_topics = await self.client.zrevrange(
            self.keys['topic_heat'],
            0, 19,
            withscores=True
        )
        
        # 获取详细信息
        detailed_topics = []
        for topic_id, score in hot_topics:
            five_q_key = self.keys['five_questions'].format(topic_id=topic_id)
            six_h_key = self.keys['six_has'].format(sector=topic_id[:6])  # 假设前6位是板块代码
            
            five_q_data = await self.client.hgetall(five_q_key)
            six_h_data = await self.client.hgetall(six_h_key)
            
            detailed_topics.append({
                'topic_id': topic_id,
                'score': score,
                'five_questions': five_q_data,
                'six_has': six_h_data,
                'timestamp': datetime.now().isoformat()
            })
        
        # 缓存排行榜结果
        await self.client.setex(
            'topics:heat:rank:detailed',
            300,  # 5分钟缓存
            json.dumps(detailed_topics)
        )
        
        return detailed_topics
    
    async def push_signal(self, signal_type: str, data: Dict):
        """推送交易信号到队列"""
        signal = {
            'type': signal_type,
            'data': data,
            'timestamp': datetime.now().isoformat(),
            'priority': self._calculate_priority(signal_type, data)
        }
        
        # 使用优先级队列
        await self.client.zadd(
            self.keys['signal_queue'],
            {json.dumps(signal): signal['priority']}
        )
    
    def _calculate_priority(self, signal_type: str, data: Dict) -> float:
        """计算信号优先级"""
        priority_map = {
            'main_topic_confirmed': 100,
            'five_questions_high': 80,
            'six_has_strong': 70,
            'warning': 50,
            'info': 10
        }
        
        base_priority = priority_map.get(signal_type, 10)
        
        # 根据置信度调整优先级
        confidence = data.get('confidence', 0.5)
        return base_priority * confidence

        self.positive_words = ['涨', '利好', '机会', '牛', '突破', '创新高', '强势', '爆发', '超预期']
        self.negative_words = ['跌', '利空', '风险', '熊', '下滑', '亏损', '下跌', '调整', '不及预期']
        
    async def collect_and_score(self, url: str) -> Dict:
        """完整的数据采集与评分流程"""
        # 1. 采集数据
        news = await self.collect_news(url)
        
        # 2. 提取关键信息
        processed = await self.preprocess_news(news)
        
        # 3. 计算5问得分
        five_q_scores = self.calculate_five_questions(processed)
        
        # 4. 识别题材
        sector = self.identify_sector(processed)
        
        return {
            'news': processed.__dict__,
            'five_questions': five_q_scores,
            'sector': sector,
            'timestamp': datetime.now().isoformat()
        }
    
    async def collect_news(self, url: str) -> FinancialNews:
        """采集单条新闻"""
        async with async_playwright() as p:
            browser = await p.chromium.launch(headless=True)
            context = await browser.new_context(
                user_agent='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
                viewport={'width': 1920, 'height': 1080}
            )
            
            page = await context.new_page()
            
            try:
                # 访问页面
                await page.goto(url, wait_until='networkidle', timeout=10000)
                
                # 智能等待内容加载
                await page.wait_for_timeout(3000)
                
                # 提取标题和内容
                title_elem = await page.query_selector('h1, .article-title, .title')
                content_elem = await page.query_selector('.article-content, .content, .article')
                
                # 提取时间
                time_elem = await page.query_selector('.time, .publish-time, .date')
                
                title = await title_elem.inner_text() if title_elem else "无标题"
                content = await content_elem.inner_text() if content_elem else ""
                
                # 解析时间
                time_str = await time_elem.inner_text() if time_elem else datetime.now().strftime('%Y-%m-%d %H:%M:%S')
                
                # 生成唯一ID
                news_id = f"news_{hash(url) % 1000000}"
                
                return FinancialNews(
                    id=news_id,
                    title=title.strip(),
                    content=content.strip(),
                    source=url,
                    publish_time=self.parse_time(time_str),
                    url=url
                )
                
            except Exception as e:
                print(f"采集失败 {url}: {e}")
                return None
            finally:
                await browser.close()
    
    async def preprocess_news(self, news: FinancialNews) -> FinancialNews:
        """新闻预处理"""
        if not news:
            return None
            
        # 1. 提取关键词
        text = news.title + " " + news.content
        keywords = jieba.analyse.extract_tags(text, topK=10, withWeight=False)
        news.keywords = keywords
        
        # 2. 情绪分析
        sentiment_score = self.analyze_sentiment(text)
        news.sentiment = sentiment_score
        
        # 3. 提取标签
        news.tags = self.extract_tags(text)
        
        return news
    
    def calculate_five_questions(self, news: FinancialNews) -> Dict[str, float]:
        """计算5问得分（每条消息单独计算）"""
        
        if not news:
            return {}
            
        text = news.title + " " + news.content
        text_lower = text.lower()
        
        scores = {}
        
        # 1. 突发性 (0-100分)
        scores['suddenness'] = self.calc_suddenness_score(news)
        
        # 2. 大事件 (0-100分)
        scores['event_scale'] = self.calc_event_scale_score(text_lower)
        
        # 3. 想象空间 (0-100分)
        scores['imagination'] = self.calc_imagination_score(text_lower)
        
        # 4. 预期差 (0-100分)
        scores['expectation_gap'] = self.calc_expectation_gap_score(text_lower)
        
        # 5. 情绪 (0-100分，50为中性)
        scores['sentiment'] = (news.sentiment + 1) * 50  # 将-1~1转换为0~100
        
        # 综合得分（加权平均）
        weights = {
            'suddenness': 0.25,
            'event_scale': 0.25, 
            'imagination': 0.20,
            'expectation_gap': 0.15,
            'sentiment': 0.15
        }
        
        scores['comprehensive'] = sum(
            scores[key] * weights[key] for key in weights.keys()
        )
        
        return scores
    
    def calc_suddenness_score(self, news: FinancialNews) -> float:
        """计算突发性得分"""
        # 基于发布时间的新鲜度
        now = datetime.now()
        publish_time = news.publish_time
        
        # 计算时间差（小时）
        hours_diff = (now - publish_time).total_seconds() / 3600
        
        # 时间越近得分越高
        if hours_diff < 1:
            return 95  # 1小时内
        elif hours_diff < 3:
            return 85  # 3小时内
        elif hours_diff < 6:
            return 70  # 6小时内
        elif hours_diff < 12:
            return 50  # 12小时内
        else:
            return 30  # 超过12小时
    
    def calc_event_scale_score(self, text: str) -> float:
        """计算大事件规模得分"""
        score = 0
        
        # 1. 关键词匹配（政策类权重高）
        policy_keywords = ['政策', '规划', '指导意见', '实施方案', '国家级', '国务院']
        tech_keywords = ['突破', '首创', '首次', '全球领先', '世界第一']
        finance_keywords = ['百亿', '千亿', '万亿', '重大项目', '战略投资']
        
        for keyword in policy_keywords:
            if keyword in text:
                score += 20  # 政策类影响大
        
        for keyword in tech_keywords:
            if keyword in text:
                score += 15  # 技术突破
        
        for keyword in finance_keywords:
            if keyword in text:
                score += 10  # 资金规模
        
        # 2. 涉及行业数量
        involved_sectors = 0
        for sector, keywords in self.sector_keywords.items():
            if any(kw in text for kw in keywords):
                involved_sectors += 1
        
        score += min(20, involved_sectors * 5)  # 每涉及一个行业加5分，最多20分
        
        # 3. 机构提及（券商、基金等）
        institution_keywords = ['中信', '中金', '国泰君安', '高盛', '摩根', '基金', '机构']
        institution_count = sum(1 for kw in institution_keywords if kw in text)
        score += min(10, institution_count * 2)
        
        return min(score, 100)  # 限制最高100分
    
    def calc_imagination_score(self, text: str) -> float:
        """计算想象空间得分"""
        score = 0
        
        # 1. 未来导向词汇
        future_words = ['未来', '预计', '有望', '潜力', '增长', '空间', '蓝海', '前景', '趋势']
        for word in future_words:
            count = text.count(word)
            score += count * 3
        
        # 2. 具体数字预测
        import re
        # 匹配增长百分比
        growth_patterns = r'增长(\d+(\.\d+)?)%|增速(\d+(\.\d+)?)%|增长率(\d+(\.\d+)?)%'
        growth_matches = re.findall(growth_patterns, text)
        if growth_matches:
            # 取最高的增长率
            growth_rates = []
            for match in growth_matches:
                for group in match:
                    if group and group.replace('.', '').isdigit():
                        try:
                            growth_rates.append(float(group))
                        except:
                            pass
            
            if growth_rates:
                max_growth = max(growth_rates)
                if max_growth > 100:
                    score += 40
                elif max_growth > 50:
                    score += 30
                elif max_growth > 20:
                    score += 20
                elif max_growth > 10:
                    score += 15
                else:
                    score += 10
        
        # 3. 市场规模预测
        market_patterns = r'(\d+(\.\d+)?)[万亿]元市场|规模[达至](\d+(\.\d+)?)[万亿]元'
        market_matches = re.findall(market_patterns, text)
        if market_matches:
            score += 25
        
        # 4. 技术革命性词汇
        revolutionary_words = ['革命', '颠覆', '变革', '重塑', '重构', '范式转移']
        for word in revolutionary_words:
            if word in text:
                score += 15
        
        return min(score, 100)
    
    def calc_expectation_gap_score(self, text: str) -> float:
        """计算预期差得分"""
        score = 50  # 中性基准
        
        # 1. 是否超预期
        if '超预期' in text:
            score += 25
        elif '不及预期' in text or '低于预期' in text:
            score -= 20
        
        # 2. 意外性词汇
        unexpected_words = ['意外', '突然', '突发', '紧急', '重磅', '罕见']
        unexpected_count = sum(1 for word in unexpected_words if word in text)
        score += unexpected_count * 5
        
        # 3. 历史对比词汇
        history_words = ['历史新高', '创纪录', '首次', '前所未有', '史无前例']
        for word in history_words:
            if word in text:
                score += 10
        
        return max(0, min(score, 100))  # 确保在0-100之间
    
    def analyze_sentiment(self, text: str) -> float:
        """分析文本情绪"""
        # 简单基于词典的情绪分析
        words = jieba.lcut(text)
        word_count = len(words)
        
        if word_count == 0:
            return 0.0
        
        positive_count = sum(1 for word in words if word in self.positive_words)
        negative_count = sum(1 for word in words if word in self.negative_words)
        
        # 计算净情绪值
        net_sentiment = (positive_count - negative_count) / word_count
        
        # 限制在-1到1之间
        return max(-1.0, min(1.0, net_sentiment * 10))
    
    def extract_tags(self, text: str) -> List[str]:
        """提取标签"""
        tags = []
        
        # 1. 行业标签
        for sector, keywords in self.sector_keywords.items():
            if any(kw in text for kw in keywords):
                tags.append(sector)
        
        # 2. 事件类型标签
        event_types = ['政策', '业绩', '并购', '技术', '产品', '合作', '订单', '融资']
        for event in event_types:
            if event in text:
                tags.append(event)
        
        return list(set(tags))  # 去重
    
    def identify_sector(self, news: FinancialNews) -> str:
        """识别主要题材板块"""
        if not news or not news.tags:
            return "其他"
        
        # 统计标签出现频率
        tag_counter = Counter(news.tags)
        
        # 优先选择行业标签
        sector_tags = [tag for tag in news.tags if tag in self.sector_keywords.keys()]
        
        if sector_tags:
            # 返回最相关的行业
            return max(sector_tags, key=lambda x: tag_counter.get(x, 0))
        else:
            # 如果没有明确行业标签，根据关键词判断
            text = news.title + " " + news.content
            for sector, keywords in self.sector_keywords.items():
                if any(kw in text for kw in keywords[:3]):  # 只检查前3个核心关键词
                    return sector
        
        return "其他"
    
    def parse_time(self, time_str: str) -> datetime:
        """解析时间字符串"""
        try:
            # 尝试多种时间格式
            formats = [
                '%Y-%m-%d %H:%M:%S',
                '%Y年%m月%d日 %H:%M',
                '%Y/%m/%d %H:%M',
                '%Y-%m-%d %H:%M',
                '%Y-%m-%d'
            ]
            
            for fmt in formats:
                try:
                    return datetime.strptime(time_str.strip(), fmt)
                except:
                    continue
            
            # 如果都失败，返回当前时间
            return datetime.now()
        except:
            return datetime.now()
