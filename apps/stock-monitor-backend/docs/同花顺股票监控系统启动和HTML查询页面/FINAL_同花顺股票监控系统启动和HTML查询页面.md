## 🚀 系统功能概览

### 核心功能
- **Chrome插件数据接收**: 支持批量股票数据提交
- **智能数据去重**: 基于股票代码的自动去重机制
- **实时股票搜索**: 支持股票代码和名称的模糊搜索
- **HTML查询页面**: 用户友好的Web界面
- **分页数据展示**: 高效的大数据量分页处理
- **响应式设计**: 适配多种设备屏幕

### 技术架构
- **后端框架**: FastAPI (Python)
- **数据库**: MySQL 8.0
- **前端**: HTML5 + CSS3 + JavaScript
- **服务端口**: 8001
- **部署方式**: 本地部署 + Docker支持
