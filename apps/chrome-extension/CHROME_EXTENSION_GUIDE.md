## 🔧 Chrome扩展安装步骤

### 步骤1: 打开Chrome扩展管理页面
1. 打开Chrome浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 或者通过菜单：**更多工具** → **扩展程序**

### 步骤2: 启用开发者模式
1. 在扩展管理页面右上角
2. 打开 **"开发者模式"** 开关

### 步骤3: 加载扩展
1. 点击 **"加载已解压的扩展程序"** 按钮
2. 选择项目目录：`/Users/mac/ok-mcp/app/chrome-extension/.output/chrome-mv3`
3. 点击 **"选择文件夹"**

### 步骤4: 验证安装
✅ 扩展应该出现在扩展列表中  
✅ 扩展名称：**同花顺股票监控助手**  
✅ 版本：**0.0.6**  
✅ 状态：**已启用**  

## 🎯 功能使用指南

### 主要功能
1. **📊 实时股票数据抓取** - 自动监控同花顺网站股票数据
2. **🔄 智能数据同步** - 与后端API实时同步数据
3. **📱 侧边栏面板** - 便捷的数据查看和控制界面
4. **🛡️ 错误处理机制** - 智能重试和异常恢复

### 使用步骤

#### 1. 打开侧边栏
- 点击Chrome工具栏中的扩展图标
- 或者右键点击扩展图标 → **"打开侧边栏"**

#### 2. 导航到同花顺网站
- 在侧边栏中点击 **"🚀 打开同花顺自选股"** 按钮
- 或者手动访问：https://t.10jqka.com.cn/

#### 3. 开始数据监控
- 在侧边栏切换到 **"同花顺"** 标签页
- 点击 **"开始监听"** 按钮
- 扩展将自动开始抓取股票数据

#### 4. 查看数据
- 在侧边栏中实时查看抓取的股票数据
- 数据包括：股票代码、名称、价格、涨跌幅等
- 支持最多显示5条最新数据

## 🛠️ 故障排除

### 常见问题

#### 1. 扩展加载失败
**症状**：点击"加载已解压的扩展程序"后出现错误  
**解决方案**：
- 确认选择的是 `.output/chrome-mv3` 目录
- 检查 `manifest.json` 文件是否存在
- 重新构建项目：`pnpm run build`

#### 2. 侧边栏无法打开
**症状**：点击扩展图标没有反应  
**解决方案**：
- 检查扩展是否已启用
- 刷新扩展：在扩展管理页面点击刷新按钮
- 重新加载扩展

#### 3. 数据抓取不工作
**症状**：点击"开始监听"后没有数据显示  
**解决方案**：
- 确认已登录同花顺账户
- 检查后端API服务是否运行（端口8001）
- 查看浏览器开发者工具Console的错误信息
- 确认在同花顺相关页面进行操作

#### 4. API连接失败
**症状**：扩展显示网络错误  
**解决方案**：
- 确认后端服务运行：`curl http://localhost:8000/api/v1/health`
- 检查防火墙设置
- 确认API端口配置正确（8000）
