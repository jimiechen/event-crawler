# Chrome MCP Server 扩展安装指南

## 📦 扩展包信息

- **文件大小**: 9.0MB
- **版本**: 0.0.6

## 🚀 安装步骤

### 方法一：开发者模式安装（推荐）

1. **打开Chrome扩展管理页面**
   - 在Chrome浏览器中输入：`chrome://extensions/`
   - 或者：菜单 → 更多工具 → 扩展程序

2. **启用开发者模式**
   - 在页面右上角打开"开发者模式"开关

3. **解压扩展文件**
   ```bash
   cd /Users/mac/ok-mcp/app/chrome-extension/.output/
   unzip chrome-mcp-server-0.0.6-chrome.zip -d chrome-mcp-server-extension/
   ```

4. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择解压后的文件夹：`chrome-mcp-server-extension/`

### 方法二：直接使用构建目录

1. **打开Chrome扩展管理页面**
   - 在Chrome浏览器中输入：`chrome://extensions/`

2. **启用开发者模式**
   - 在页面右上角打开"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择目录：`/Users/mac/ok-mcp/app/chrome-extension/.output/chrome-mv3/`

## 🐛 故障排除

### 常见问题

1. **扩展无法加载**
   - 确认Chrome版本支持Manifest V3
   - 检查文件权限
   - 查看Chrome扩展页面的错误信息

2. **功能异常**
   - 打开Chrome开发者工具
   - 查看Console面板的错误信息
   - 检查扩展的后台页面日志

3. **权限问题**
   - 确认扩展已获得所需权限
   - 重新安装扩展
   - 检查网站的安全策略

### 日志查看

- **扩展后台日志**：Chrome扩展页面 → 点击扩展详情 → 检查视图：背景页
- **内容脚本日志**：在目标网页按F12 → Console面板
- **弹出窗口日志**：右键扩展图标 → 检查弹出式窗口

## 📞 技术支持
