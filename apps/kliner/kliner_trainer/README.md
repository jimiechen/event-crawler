# K线双盲训练系统

## 项目简介

K线双盲训练系统是一个基于 Flutter 开发的股票K线训练应用，帮助用户通过双盲训练提高股票交易技能。

## 核心功能

### 1. 仓位管理
- **1层 = 1万（10000元）**
- **3层 = 3万（30000元）**
- **5层 = 5万（50000元）= 满仓**
- 起始资金：100000元
- 使用收盘价作为买入/卖出价格
- 允许清仓（卖出超过买入仓位）

### 2. 收益率计算
- 买入时记录买入价格（使用当天收盘价）
- 卖出时使用当天收盘价计算收益率
- 观望时计算当前持仓收益率
- 收益率以百分比形式显示
- 正收益：红色
- 亏损：绿色
- 平盘：灰色

### 3. 随机算法
- 随机选择任意时间段的股票数据
- 不限制年份范围
- 避免K线越界

### 4. UI 优化
- 仓位按钮显示"1万"、"2万"、"3万"、"4万"、"5万"
- 当前仓位显示"X万"格式
- K线图占主屏幕大部分（flex: 8）
- 添加了关闭按钮（右上角）
- 移除了操作理由输入框
- 移除了"下一天"按钮

### 5. 自动跳转
- 操作后自动调用 `nextDay()`
- K线往后移动1天
- 显示下一天的K线数据

### 6. K线图功能
- 支持放大缩小（10-60根K线）
- 左下角有左右切换按钮
- 每次操作后K线往后移动1天
- 显示EXPMA5、EXPMA13指标
- 显示成交量指标（初学者模式）
- 显示地量信号

### 7. 难度模式
- **初学者模式**：显示全部指标，60天数据
- **中级模式**：隐藏成交量指标，40天数据
- **高级模式**：只显示K线，30天数据
- **大师模式**：完全双盲，20天数据

### 8. 技术信号
- **金叉**：EXPMA5上穿EXPMA13，看涨信号
- **死叉**：EXPMA5下穿EXPMA13，看跌信号
- **地量**：成交量低于60日均量一半，可能变盘
- **强烈买入**：金叉+地量
- **买入**：金叉
- **卖出**：死叉
- **观望**：其他情况

### 9. 训练流程
1. 开始训练：随机选择股票和起始天数
2. 按天逐步进行：每次操作后自动跳转到第二天
3. 执行操作：买入、卖出、观望
4. 计算收益率：实时反映当前持仓收益
5. 显示复盘：显示操作结果和技术信号
6. 结束训练：显示最终总结

### 10. 数据统计
- 训练次数
- 得分统计
- 当前资金
- 持仓市值
- 收益率显示
- 操作历史记录

## 技术栈

- **Flutter**：跨平台移动应用框架
- **GetX**：状态管理和路由管理
- **CSV Data**：股票数据存储和读取
- **EXPMA**：指数移动平均线指标计算
- **成交量**：成交量指标计算

## 安装和运行

### 前置要求
- Flutter SDK 3.22.0 或更高版本
- Dart SDK 3.4.0 或更高版本
- iOS 12.0 或更高版本
- Android 5.0 (API level 21) 或更高版本

### 安装步骤

1. 克隆项目
```bash
git clone <repository-url>
cd kliner_trainer
```

2. 安装依赖
```bash
flutter pub get
```

3. 运行应用
```bash
flutter run
```

## 使用说明

### 开始训练
1. 打开应用，点击"开始训练"按钮
2. 系统随机选择股票和起始天数
3. 显示K线图和相关指标

### 执行操作
1. 选择仓位：点击"1万"、"2万"、"3万"、"4万"、"5万"按钮
2. 选择操作：点击"买入"、"观望"、"卖出"按钮
3. 系统自动跳转到下一天
4. 查看收益率：实时显示当前持仓收益

### 查看复盘
1. 每次操作后显示复盘对话框
2. 显示操作类型、仓位、价格
3. 显示技术信号（金叉、死叉、地量等）
4. 显示收益率和得分

### 结束训练
1. 点击右上角关闭按钮或"结束训练"按钮
2. 显示最终总结
3. 查看股票、时间段、操作次数、收益率、训练天数
