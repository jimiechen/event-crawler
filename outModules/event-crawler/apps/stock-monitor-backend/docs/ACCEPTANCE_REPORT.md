## 5. 缺陷修复记录

在验收测试过程中发现并修复了以下问题：
1. **数据库Schema问题**: `StockData` 模型中的 `symbol` 字段名与数据库表 `stock_prices` 中的 `code` 字段名不一致，导致 SQLAlchemy 映射错误。已修正模型定义。
2. **测试用例逻辑问题**: `test_quant_monitor.py` 中未重置单例 `strategy_service` 的状态，导致测试受此前测试运行影响（冷却时间未重置）。已在测试前添加状态重置代码。
3. **数据库视图依赖**: 数据库初始化脚本中视图创建顺序依赖表的存在，已调整脚本确保表先创建。
